# Builds

Production installers for Notebook, grouped by platform.

```
builds/
├── macos/    Notebook_<version>_<arch>.dmg, .app.zip
├── linux/    Notebook_<version>_<arch>.deb, .AppImage
└── windows/  Notebook_<version>_<arch>-setup.exe
```

Each folder contains a `SHA256SUMS.txt` generated by the build script.

## Regenerating

From the repository root:

```bash
npm ci
npm run doctor         # verify the local toolchain
npm run build:current  # build for this operating system
```

Or pick a target explicitly:

```bash
npm run build:macos     # must run on macOS
npm run build:windows   # native on Windows, or cross-compile with cargo-xwin
npm run build:linux     # native on Linux, or via Docker from macOS
npm run build:all       # every target this host can produce
```

The macOS DMG opens with a drag-to-Applications window (background at
`src-tauri/icons/dmg-background.png`). For a universal build, install both Rust
targets once:

```bash
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm run build:macos -- --arch universal
```

## Cross-compiling Windows

One-time setup on macOS or Linux:

```bash
rustup target add x86_64-pc-windows-msvc
cargo install cargo-xwin
brew install llvm nsis          # macOS
sudo apt install llvm nsis      # Linux
```

Then run `npm run build:windows`. Use `--arch aarch64` for Windows on ARM.

## Cross-compiling Linux

`npm run build:linux` from macOS uses Docker (`rust:1.98-bookworm`), so no Linux
packages need to be installed on the host. Pass `--arch x86_64` to target
Intel/AMD (the default follows the host architecture).

## Notes

- Binaries in these folders are ignored by git — rebuild them when you need a release.
- Builds are unsigned by default. See the signing section in the top-level README.
- CI builds all three platforms in parallel: `.github/workflows/build.yml`.
